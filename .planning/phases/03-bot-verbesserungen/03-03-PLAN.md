    1. State: `const [drafts, setDrafts] = useState<Record<string, Record<string, string | number | boolean>>>({})` und `const [sending, setSending] = useState<string | null>(null)`.
    2. `sendParameters(botId: string)`: liest `drafts[botId]`; bei leer → return. Setzt `sending=botId`; `fetch('/api/bridge/command', { method:'POST', headers:{'Content-Type':'application/json'}, body: JSON.stringify({ bridgeId: botId, command: 'set_parameters', payload: { parameters } }) })`. Bei `!res.ok` Fehler in `console.error('[BotsSettings] ...')` loggen (Konvention CLAUDE.md: getaggte Logs). Im `finally` `setSending(null)`. Optional 2s-Erfolgs-Feedback via separatem State (UI-SPEC „Gesendet ✓").
    3. `renderParameterEditor(botId, parameters: Record<string, string|number|boolean> | undefined)`: bei `!parameters || Object.keys(parameters).length === 0` → Info-Text „Dieser Bot unterstützt keine konfigurierbaren Parameter." in `var(--text-3)`, KEIN Button (D-11, UI-SPEC). Sonst: `draft = drafts[botId] ?? parameters`; pro `Object.entries(draft)` eine Zeile (`flex items-center justify-between gap-3`) mit Label (`text-[11px] font-bold uppercase tracking-wide`, `var(--text-2)`) und typ-passendem Input:
       - `typeof value === 'boolean'` → `<button role="switch" aria-checked={value} aria-label={key}>`-Toggle, 44×24px, `var(--green)` wenn true sonst `var(--surface-2)` (UI-SPEC nennt surface-3 für false-Track — verwende den in globals.css existierenden Token; falls `--surface-3` nicht existiert, `--surface-2`). onClick toggelt `drafts[botId][key]`.
       - `typeof value === 'number'` → `<input type="number" aria-label={key}>`, onChange `parseFloat`.
       - sonst (string) → `<input type="text" aria-label={key}>`.
       Inputs schreiben in `setDrafts(prev => ({ ...prev, [botId]: { ...(prev[botId] ?? parameters), [key]: next } }))`.
       Darunter Pro-Bot-Button (D-15): `<button onClick={() => sendParameters(botId)} disabled={sending===botId} aria-busy={sending===botId}>` mit `Check size={12}` + Label „Parameter senden" (während Senden „Senden...", UI-SPEC). Style `background: var(--accent), color:#fff, px-3 py-2 rounded-xl text-[11px] font-bold` (UI-SPEC). Button nur bei vorhandenen Parametern (im else-Zweig).
    4. Im read-only View-Block (aus Task 1) nach der Bot-Info einen Trenner `border-t var(--border)` und darunter `{renderParameterEditor(bot.id, status?.parameters)}` aufrufen. `status?.parameters` ist optional (Pitfall 2) — bei undefined greift der Info-Text-Zweig.
